# Qué se copia de Polaris a esta carpeta. Lo lee backend/scripts/polaris_sync.py.
# Regla del proyecto: se copia LITERAL; los cambios se deciden después, aparte (ORIGEN.md).
#
#   commit <sha>   commit de Polaris del que se copia
#   root <módulo>  herramienta pedida; se copian también todos los módulos que importa (cierre)
#   data <ruta>    fichero o carpeta de tools/ que leen esos módulos (sin node_modules)
#   extra <ruta>   fichero o carpeta fuera de tools/ (evals/, docs/)
#   tests auto     las pruebas de Polaris que solo usan lo copiado, con sus ayudantes,
#                  fixtures y campañas de mutantes (polaris_sync.eligible_tests)
#   test <fichero> una prueba pedida por su nombre: prueba algo copiado, pero `tests auto` no
#                  la reconoce porque no nombra una herramienta `x.py` (polaris_sync.named_tests)
#   fichas auto    la ficha de cada herramienta copiada (tools/fichas/, polaris_sync.cards_for)
